# PRD — 모의고사 연습장 (Answer Sheet)

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 |
| 작성일 | 2026-08-12 |
| 상태 | v1 구현 완료 · 검증 대기 |
| 대상 릴리스 | v1 (개인용 단일 사용자) |

---

## 1. 개요

자격증 시험 준비자가 **자신이 보유한 기출문제를 직접 데이터화하여 반복 응시**하고, **틀린 문제만 골라 다시 푸는** 것을 목표로 하는 웹 기반 모의고사 애플리케이션.

시중 문제은행 서비스는 원하는 자격증이 없거나, 있어도 자신이 확보한 기출·오답 자료를 넣을 수 없다. 이 제품은 문제 콘텐츠를 사용자가 소유하고, 앱은 **출제 · 채점 · 오답 추적**만 담당한다.

### 한 줄 정의
> 내 기출문제를 넣으면 시험지가 되고, 틀린 문제는 저절로 오답노트가 되는 개인 연습장.

---

## 2. 문제 정의와 목표

### 해결하려는 문제

| 문제 | 현재 상황 | 제품의 해결 방식 |
|---|---|---|
| 기출 PDF는 있는데 풀 방법이 없다 | 인쇄하거나 화면으로 눈으로만 훑음 | PDF 첨부 → AI가 문제·선지·과목을 자동 추출 |
| 채점이 수동이라 반복이 힘들다 | 답안지 대조에 시간 소모 | 번호 클릭 마킹 → 즉시 자동 채점 |
| 틀린 문제를 다시 안 본다 | 오답을 따로 정리하지 않음 | 오답 자동 누적, 오답만 재시험 |
| 어느 과목이 약한지 모른다 | 총점만 기억 | 과목별 정답률 자동 집계 |
| 서비스에 데이터를 묶이고 싶지 않다 | 계정 종속 | JSON 내보내기/가져오기로 완전 이전 가능 |

### 성공 기준 (v1)

- 80문항 기출 PDF 한 부를 **5분 이내**에 응시 가능한 상태로 등록할 수 있다.
- 한 번 등록한 시험을 재응시할 때 **추가 입력 작업이 0**이다.
- 오답노트에 쌓인 문제가 반복 학습을 통해 **자동으로 비워진다**(연속 2회 정답 시 제외).
- 브라우저 데이터가 초기화돼도 JSON 백업으로 **문제·오답 기록이 온전히 복원**된다.

### 비목표 (v1에서 하지 않는 것)

- 다중 사용자, 계정, 로그인, 서버 동기화
- 문제 공유·거래·커뮤니티
- 실기 시험의 코드 채점, 서술형 자동 채점
- 학습 스케줄링(망각곡선 기반 알림 등)

## 3. 대상 사용자

**주 사용자: 자격증 필기시험 준비자 (개인)**

- 기출문제를 PDF/HWP 형태로 이미 확보하고 있다
- 같은 시험을 여러 회차 반복해서 푼다
- 한 시험 안에 과목이 여러 개이며, 과목별 과락 기준이 있다
- 실기 대비 시 주관식 단답 암기가 필요하다

**사용 맥락:** 주로 PC 브라우저, 짧은 자투리 시간에는 모바일. 오프라인 응시 가능성 있음.

## 4. 핵심 사용자 흐름

```
[시험 만들기] → [문제 등록] → [응시] → [채점 결과] → [오답노트] ┐
                    ↑                                              │
                    └──────────── 오답만 재시험 ←───────────────────┘
```

### 4.1 문제 등록 (3가지 경로)

| 경로 | 사용 상황 | 소요 |
|---|---|---|
| **PDF 자동 추출** | 기출 PDF 파일이 있을 때 (기본 경로) | 80문항 1~2분 |
| **일괄 붙여넣기** | 텍스트로 정리된 문제가 있을 때 | 즉시 |
| **직접 입력** | 문제에 이미지(그래프·표)가 포함될 때, 오탈자 수정 | 문제당 30초 |

### 4.2 응시

시험 시작 전 다음을 선택한다.

- **범위**: 전체 / 특정 과목 / 특정 회차 / 문항 수 제한
- **모드**: 실전(끝까지 푼 뒤 일괄 채점) / 학습(한 문제 답하면 즉시 해설)
- **옵션**: 문제 순서 랜덤 섞기, 제한시간(분)

응시 화면은 한 번에 한 문제를 보여주고, 하단의 **답안지 스트립**으로 전체 마킹 현황을 확인하고 임의 문항으로 점프할 수 있다.

## 5. 기능 요구사항

### FR-1 시험 관리
- FR-1.1 시험을 이름으로 생성/삭제한다. 시험은 문제·오답기록을 각각 독립적으로 보유한다.
- FR-1.2 시험 목록에 최근 응시 점수를 표시한다.
- FR-1.3 시험 삭제 시 소속 문제·이미지·통계를 함께 삭제하며, 삭제 전 확인 단계를 거친다.

### FR-2 문제 등록 — PDF 자동 추출
- FR-2.1 PDF 첨부 시 1차로 **총 문항 수, 과목별 문항 구간, 정답표 존재 여부**를 파악한다.
- FR-2.2 파악된 과목 구간에 따라 각 문제에 과목을 자동 부여한다.
- FR-2.3 문제를 **4문항 단위 배치**로 나누어 지문·선지·정답을 추출한다.
- FR-2.4 배치 응답이 잘리거나 파싱에 실패하면 배치 크기를 4 → 2 → 1로 줄여 재시도한다.
- FR-2.5 1문항으로도 실패한 번호는 건너뛰고 **문항 번호를 사용자에게 고지**한다.
- FR-2.6 PDF에 정답표가 없으면 AI가 문제를 풀어 정답을 채우고, 해당 문제에 `정답 검토` 플래그를 남긴다.
- FR-2.7 진행률(추출 문항 / 전체 문항)을 실시간 표시하고, 중단 시 그 시점까지의 결과를 보존한다.
- FR-2.8 등록 전 추출 결과를 미리보기로 확인할 수 있다.
- FR-2.9 회차 값을 일괄 지정할 수 있다. 해설 자동 생성은 선택 옵션이다.

### FR-3 문제 등록 — 붙여넣기 / 직접 입력
- FR-3.1 텍스트 파서 규칙: `1.` 또는 `1,` = 문제 시작, `①`~`⑩` 또는 `1)` = 선지, `정답:` / `해설:` = 각 필드.
- FR-3.2 선지가 없으면 주관식, 정답이 복수면 복수정답으로 자동 판정한다.
- FR-3.3 직접 입력 시 선지는 개수 제한 없이 추가/삭제한다(4지·5지 혼재 지원).
- FR-3.4 정답은 선지 번호 마킹으로 지정한다. 복수정답은 다중 마킹한다.
- FR-3.5 문제 이미지는 **Ctrl+V 붙여넣기** 또는 파일 선택으로 첨부한다.
- FR-3.6 과목·회차는 기존 입력값을 자동완성 후보로 제공한다.

### FR-4 응시
- FR-4.1 문제 순서 랜덤 섞기를 선택할 수 있다.
- FR-4.2 제한시간을 분 단위로 설정하며, 0이 되면 자동 제출한다. 잔여 60초 미만은 강조 표시한다.
- FR-4.3 학습 모드에서는 단일정답 문항 선택 즉시 정답·해설을 노출하고 답변을 잠근다. 복수정답·주관식은 "정답 확인" 버튼으로 노출한다.
- FR-4.4 실전 모드에서는 제출 전까지 정답을 노출하지 않는다.
- FR-4.5 답안지 스트립으로 마킹 현황 확인 및 문항 이동이 가능하다.

### FR-5 채점
- FR-5.1 단일정답: 선택 번호 일치 시 정답.
- FR-5.2 복수정답: 선택 집합이 정답 집합과 **완전히 일치**해야 정답(부분점수 없음).
- FR-5.3 주관식: **공백 제거 + 소문자 변환** 후 비교하며, 등록된 복수 정답 중 하나와 일치하면 정답.
- FR-5.4 무응답은 오답으로 처리한다.
- FR-5.5 결과 화면에 총점(100점 환산), 정답/오답 수, **과목별 정답률 막대**, 오답 문항 상세(내 답·정답·해설)를 표시한다.
- FR-5.6 결과 화면에서 해당 회차의 오답만 즉시 재응시할 수 있다.

### FR-6 오답노트
- FR-6.1 오답 발생 시 해당 문제를 오답노트에 등록하고 `오답 횟수`를 누적한다.
- FR-6.2 정답 시 `연속정답` 카운터를 1 증가시킨다. **연속 2회 정답 시 오답노트에서 자동 제외**한다.
- FR-6.3 오답 발생 시 연속정답 카운터를 0으로 초기화한다.
- FR-6.4 오답노트 항목에 오답 횟수, 연속정답 진행도(n/2), 과목, 정답을 표시한다.
- FR-6.5 오답노트 전체를 학습 모드·랜덤 순서로 즉시 재응시할 수 있다.
- FR-6.6 탭에 오답 개수 배지를 표시한다.

### FR-7 데이터 백업
- FR-7.1 시험 단위로 JSON 내보내기를 지원한다(문제 + 정답 + 오답 통계).
- FR-7.2 이미지 포함/텍스트만 두 가지 모드를 제공한다.
- FR-7.3 JSON 가져오기 시 새 시험으로 생성하며 이미지와 오답 기록을 복원한다.

## 6. 데이터 모델

### 저장 키 구조

| 키 | 내용 | 분리 이유 |
|---|---|---|
| `exams:index` | 시험 목록(메타데이터) | 목록 화면에서 전체 문제를 읽지 않기 위해 |
| `exam:{examId}:questions` | 문제 배열 | — |
| `exam:{examId}:stats` | 문제별 오답 통계 | 응시마다 갱신되므로 문제 데이터와 분리 |
| `img:{examId}:{questionId}` | 이미지 base64 | **항목당 5MB 한도를 문제 단위로 분산** |

### Question

```json
{
  "id": "a1b2c3d",
  "subject": "빅데이터 분석 기획",
  "round": "10회 필기",
  "type": "single | multi | short",
  "stem": "빅데이터 분석과 관련된 기술에 대한 설명으로 옳지 않은 것은?",
  "hasImage": false,
  "choices": ["...", "...", "...", "..."],
  "answer": [1],
  "explanation": "",
  "needsReview": true
}
```

- `answer`는 객관식이면 **0-based 선지 인덱스 배열**, 주관식이면 허용 정답 문자열 배열
- `needsReview`는 AI가 정답을 추론한 경우 true

### Stats

```json
{
  "a1b2c3d": {
    "wrong": 3,
    "streak": 1,
    "inNote": true,
    "lastWrongAt": 1754985600000
  }
}
```

## 7. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 성능 | 80문항 PDF 추출 2분 이내, 문항 전환 지연 없음 |
| 저장 | 문제 데이터는 브라우저 로컬 저장소에 영속화, 저장 실패 시 메모리로 폴백 |
| 내구성 | 저장소 초기화에 대비해 JSON 백업이 **정본 데이터 경로** 역할을 함 |
| 프라이버시 | 문제 데이터는 로컬에 저장. PDF는 추출 시점에만 AI 처리로 전송 |
| 접근성 | 마킹 버튼 최소 34px 터치 영역, 색상 외 텍스트로도 정오 구분 |
| 오프라인 | 등록된 문제의 응시·채점은 오프라인 동작. PDF 추출만 온라인 필요 |

## 8. 설계 결정 및 근거

| 결정 | 근거 | 대안 |
|---|---|---|
| 이미지를 문제별 개별 키로 저장 | 문제 배열이 커지면 단일 항목 저장 한도 초과. 분리 시 문항 수 확장에 안전 | 문제 데이터에 인라인 |
| PDF 추출을 4문항 배치로 분할 | 응답 길이 제한으로 일괄 요청 시 전체 실패. 분할 시 실패 격리 가능 | 단일 요청 |
| 실패 시 배치 크기 축소 재시도 | 특정 문항의 긴 지문 때문에 배치가 실패하는 경우가 대부분 | 즉시 실패 처리 |
| 정답 추론 시 `needsReview` 플래그 | 추론 정답은 오류 가능성이 있어 사용자 검증 유도 필요 | 무표시 등록 |
| 브라우저 기본 팝업(`prompt`/`confirm`) 미사용 | 샌드박스 환경에서 차단되어 무반응으로 보임 | 네이티브 다이얼로그 |
| 복수정답 부분점수 없음 | 실제 시험 채점 방식과 일치 | 부분점수 |
| 오답 제외 기준 연속 2회 | 1회는 우연 정답 가능, 3회는 노트가 비워지지 않음 | 1회 / 3회 / 수동 |

## 9. 알려진 제약과 리스크

| 리스크 | 영향 | 완화 |
|---|---|---|
| AI 추론 정답의 오류 | 잘못된 정답으로 학습 | `정답 검토` 플래그 + 수동 수정. 오답률이 비정상적으로 높은 문항은 정답 오류 의심 |
| 보기형 문항(가/나/다 조합), 수식·그래프 문항 추출 정확도 저하 | 일부 문항 누락·왜곡 | 건너뛴 문항 번호 고지, 직접 입력 보완 |
| 브라우저 저장소 용량 한계 | 이미지 다수 등록 시 저장 실패 | 이미지 키 분리, 텍스트 우선 등록 권장, JSON 백업 |
| HWP 직접 지원 없음 | 변환 수작업 필요 | PDF 변환 후 등록 |
| 저장소 접근 차단 환경 | 새로고침 시 데이터 소실 | 메모리 폴백 + JSON 백업 안내 |

## 10. 향후 로드맵

### v1.1 — 정확도와 편의
- 추출 결과 미리보기에서 **인라인 수정** 후 등록
- 건너뛴 문항만 재추출
- 정답 검토 대상만 모아보는 필터
- 문제 검색 및 과목/회차 일괄 편집

### v1.2 — 학습 효율
- 응시 이력 그래프(회차별 점수 추이, 과목별 추이)
- 오답 빈도 상위 문항 리포트
- 마지막 오답일 기준 복습 우선순위 정렬
- 문항별 소요 시간 기록

### v2 — 확장
- 실기 대비: 다중 빈칸, 순서 배열 문항 유형
