# PRD: 쇼핑리뷰분석 (가칭)
### 마케터용 AI 리뷰 분석 크롬 확장 프로그램

버전: v0.1 (Draft) | 작성일: 2026-08-19

---

## 1. 개요

### 1.1 한 줄 정의
쿠팡·네이버 상품 페이지에서 리뷰를 자동 파싱하여 Gemini 3.0 flash 기반으로 감성/인사이트/키워드를 분석하고, 결과를 팝업 대시보드와 엑셀 파일로 즉시 제공하는 무료 크롬 확장 프로그램.

### 1.2 배경 & 문제 정의
- 개인 마케터·1인 셀러는 경쟁 상품이나 자사 상품의 리뷰를 수십~수백 개씩 수동으로 읽고 정리해야 함.
- 리뷰 안에 있는 불만·칭찬 포인트를 마케팅 카피, 상세페이지 개선, CS 대응에 활용하고 싶지만 시간이 부족함.
- 기존 VOC(Voice of Customer) 분석 툴은 대부분 기업용/유료이며, 개인 셀러가 쓰기엔 무겁고 비쌈.

### 1.3 목표
- 상품 페이지 방문 → 클릭 한 번 → 30초 내외로 리뷰 인사이트 확보
- 텍스트 분석 결과를 "바로 쓸 수 있는" 마케팅 언어로 요약
- 리뷰 원문 데이터도 엑셀로 함께 제공해 추가 가공 가능하게 함

## 2. 타겟 사용자 & 페르소나

| 항목 | 내용 |
|---|---|
| 주 사용자 | 개인 마케터, 1인 셀러 |
| 사용 맥락 | 쿠팡/네이버에서 본인 상품 또는 경쟁 상품 페이지를 볼 때 |
| 핵심 니즈 | "이 상품 리뷰 요약 좀 빨리 보고 싶다", "상세페이지에 어떤 문구를 넣어야 할지 감이 안 온다" |
| IT 숙련도 | 중간 (엑셀은 익숙, 개발 지식 없음) |

## 3. 핵심 기능 (MVP)

### 3.1 리뷰 수집
- **방식**: 사용자가 현재 열람 중인 쿠팡/네이버 상품 상세 페이지의 DOM에서 리뷰를 직접 파싱 (별도 크롤링 서버 없음 → ToS 리스크 최소화)
- **범위**: 상품 1개당 최근 리뷰 100~300개 (페이지네이션 자동 스크롤/클릭으로 확보)
- **지원 플랫폼**: 쿠팡, 네이버 스마트스토어 (MVP 동시 지원)
- **수집 항목**: 리뷰 본문, 별점, 작성일, (가능 시) 옵션 정보

### 3.2 AI 분석 (Gemini 3.0 flash)
1. **감성분석**: 리뷰별 긍정/부정/중립 라벨링 + 전체 비율(%) 산출
2. **핵심 인사이트 요약**: 마케팅 포인트(강점 어필 요소)와 개선점을 5줄 이내로 요약
3. **키워드 마인드맵**: 리뷰에서 자주 언급되는 핵심 키워드 추출 및 키워드 간 연관 관계를 구조화하여 시각화

### 3.3 결과 제공
- **대시보드**: 확장 프로그램 팝업 내에 감성 비율 차트, 인사이트 요약, 키워드 마인드맵, 리뷰 원문 리스트를 한 화면에 배치
- **엑셀 내보내기**: 리뷰 원문 + 감성 라벨 + 키워드 태깅이 포함된 .xlsx 파일 다운로드

## 4. 사용자 플로우

1. 사용자가 쿠팡/네이버 상품 상세 페이지 방문
2. 확장 프로그램 아이콘 클릭 → 팝업 오픈
3. "리뷰 분석하기" 버튼 클릭
4. 확장 프로그램이 현재 페이지에서 리뷰 100~300개 파싱 (진행률 표시)
5. 파싱된 텍스트를 Gemini 3.0 flash API로 전송 → 분석 결과 수신
6. 팝업 내 대시보드에 결과 렌더링 (감성 비율 / 인사이트 5줄 / 마인드맵 / 리뷰 리스트)
7. "엑셀 다운로드" 버튼으로 원문 데이터 저장

---

## 5. 화면 설계 (팝업 대시보드)

크롬 확장 팝업은 공간이 제한적이므로(통상 360~450px 폭) 아래와 같이 탭 또는 스크롤 구조로 구성 제안:

```
┌─────────────────────────────┐
│ [상품명]  최근 리뷰 250개 분석완료 │
├─────────────────────────────┤
│ 😊 긍정 68%  😐 중립 12%  😞 부정 20% │  ← 감성 비율 (도넛 차트)
├─────────────────────────────┤
│ 📌 핵심 인사이트 (5줄 요약)          │
│  - 마케팅 포인트: ...              │
│  - 개선 필요: ...                  │
├─────────────────────────────┤
│ 🧠 키워드 마인드맵                  │
│   (배송 - 빠름 - 포장 상태)         │
├─────────────────────────────┤
│ 📝 리뷰 원문 (스크롤 리스트)         │
├─────────────────────────────┤
│ [엑셀로 다운로드]                  │
└─────────────────────────────┘
```

- 팝업 내 공간 제약으로 마인드맵은 간략화된 노드 그래프(주요 키워드 5~8개 중심)로 표시
- 리뷰 원문 리스트는 스크롤 + 감성 라벨 컬러 태그(초록/빨강/회색)로 구분

## 6. 기술 아키텍처 (제안)

| 영역 | 방식 |
|---|---|
| 프론트엔드 | Chrome Extension (Manifest V3), Content Script + Popup |
| 리뷰 파싱 | Content Script가 현재 활성 탭의 DOM을 읽어 리뷰 텍스트 추출 |
| AI 분석 | Popup/Background에서 Gemini 3.0 flash API 호출 (감성분석·요약·키워드 추출 프롬프트) |
| 엑셀 생성 | 클라이언트 사이드 라이브러리(예: SheetJS)로 로컬에서 .xlsx 생성 후 다운로드 |
| 데이터 저장 | 서버 저장 없이 로컬(브라우저) 처리 원칙 — 프라이버시 리스크 최소화 |

> ⚠️ 서버 없이 클라이언트에서 API 키를 직접 호출하면 키가 노출될 수 있으므로, 실제 배포 시에는 경량 프록시 서버(사용량 제한/키 보호용)를 두는 방식을 권장합니다. 이 부분은 별도 기술 검토가 필요합니다.

## 7. 리스크 및 제약사항

- **플랫폼 ToS**: 자동 크롤링(서버 수집)은 쿠팡/네이버 약관 위반 소지가 있어, MVP는 "사용자가 직접 방문한 페이지의 화면 파싱"으로 한정. 향후 URL 입력 자동 수집 기능 추가 시 법적 검토 필요.
- **DOM 구조 변경 리스크**: 쿠팡/네이버가 페이지 구조를 변경하면 파싱 로직이 깨질 수 있음 → 유지보수 이슈 상시 발생 가능.
- **API 비용**: 완전 무료 서비스이지만 Gemini API 호출 비용은 발생 → 사용자당 호출 제한(rate limit) 설계 필요.
- **개인정보**: 리뷰 작성자 닉네임 등 개인 식별 정보 포함 가능성 → 수집 시 최소화 처리 권장.

## 9. MVP 범위 정리

**포함 (MVP)**
- 쿠팡 + 네이버 스마트스토어 리뷰 파싱 (현재 페이지 기준)
- 감성분석, 5줄 인사이트, 키워드 마인드맵
- 팝업 내 대시보드
- 엑셀 원문 다운로드
- 완전 무료

**제외 (향후 로드맵 후보)**
- URL 입력 자동 다중 수집
- 경쟁사 비교 분석
- 기간별/누적 트렌드 리포트
- 대행사용 다중 클라이언트 관리 기능
- 별도 대시보드 탭(리포트 페이지) 확장
